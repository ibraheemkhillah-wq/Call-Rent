# فحوص المتصفح

فحوص تفتح التطبيق فعلاً وتضغط أزراره، لأن ما يُراد ضمانه سلوكٌ يراه
المستخدم: نسبةٌ تبقى كما حُفظت، وصفرٌ يُسجَّل قيداً، وخسارةٌ تظهر خسارةً
في التقرير المُرسَل.

## التشغيل

```bash
npm run build
npx vite preview --port 4200 --strictPort &   # أو: npm run dev -- --port 4200
npm run test:ui
```

| الملف | ما يضمنه |
|---|---|
| `rates.mjs` | النسبة الموحّدة لا تمحو النسب الخاصة، وكلٌّ يُحفظ عند صاحبه |
| `zero-loss.mjs` | الصفر قيدٌ لا فراغ، والخسارة تُسجَّل وتظهر في التقارير |
| `profits.mjs` | التوزيع، والتحويل بين المبلغ والنسبة، وثبات القيم بعد العودة |

`browser.mjs` يبحث عن playwright-core المثبَّت على الجهاز، فلا يُضيف
التطبيق تبعية لا يستعملها. وإن كان في مكان آخر: `PLAYWRIGHT_PATH=... npm run test:ui`.
