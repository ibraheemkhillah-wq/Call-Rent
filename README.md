# نظام إدارة المستثمرين

تطبيق عربي بالكامل لإدارة علاقة الشركة بمستثمريها: تسجيل المستثمرين ورؤوس أموالهم،
احتساب الأرباح الشهرية ونسبها، وإصدار تقارير **شهرية / ربع سنوية / نصف سنوية / سنوية**
بصيغة PDF بتصميم فاخر يليق بأصحاب رؤوس الأموال.

---

## التشغيل

```bash
npm install     # مرة واحدة
npm run dev     # التشغيل للتطوير  → http://localhost:5173
npm run build   # بناء نسخة الإنتاج → مجلد dist/
npm run preview # معاينة نسخة الإنتاج
```

التطبيق يعمل بالكامل في المتصفح، ولا يحتاج خادماً أو قاعدة بيانات.
مجلد `dist/` بعد البناء يمكن رفعه كما هو على أي استضافة ثابتة.

## ما الذي يقوم به التطبيق

### ١. المستثمرون
- إضافة كل مستثمر على حدة مع بياناته الكاملة (الاسم، الهاتف، البريد، رقم الهوية،
  تاريخ الانضمام، ملاحظات الاتفاقية).
- تحديد **مبلغ الاستثمار الأولي** عند الإضافة.
- تسجيل **حركات رأس المال** لاحقاً: إيداعات إضافية أو سحوبات، كل واحدة بتاريخها.
- رأس المال في أي لحظة = مجموع الإيداعات − مجموع السحوبات حتى ذلك التاريخ.

### ٢. الأرباح الشهرية
- **صفحة «الأرباح الشهرية»**: جدول واحد لتسجيل ربح كل المستثمرين لشهر معيّن دفعة واحدة.
- **من صفحة المستثمر**: تسجيل ربح شهر منفرد مع ملاحظة وحالة صرف.
- النسبة المئوية تُحتسب تلقائياً أثناء الكتابة.
- تتبّع حالة كل ربح: **مصروف** أو **مستحق** (بضغطة واحدة على الشارة).
- أداة اختيارية: أدخل **مبلغ الربح الإجمالي** للشهر واضغط «وزّع تلقائياً» فيُقسَّم على
  المستثمرين بنسبة رأس مال كل واحد — ثم يمكنك تعديل أي رقم يدوياً قبل الحفظ.

### ٣. التقارير PDF
اختر المستثمر (أو **جميع المستثمرين** دفعة واحدة) + نوع الفترة + السنة، ثم «تصدير PDF».

كل تقرير يحتوي على:

| القسم | المحتوى |
|---|---|
| الترويسة | الشعار، اسم الشركة، رقم التقرير، تاريخ الإصدار، العملة |
| بيانات المستثمر | الاسم، الهوية، الهاتف، البريد، تاريخ الانضمام، حالة الحساب |
| الأرقام الرئيسية | **كم استثمر** • **كم ربح بالدولار** • **نسبة العائد للفترة %** • **العائد السنوي المكافئ %** |
| التفصيل الشهري | لكل شهر: رأس المال، الربح، النسبة الشهرية، حالة الصرف |
| رسم بياني | تطوّر الأرباح الشهرية خلال الفترة |
| حركات رأس المال | الإيداعات والسحوبات داخل الفترة + رأس المال بداية ونهاية |
| الملخص التراكمي | إجمالي المستثمر، إجمالي الأرباح، المصروف، المستحق، العائد التراكمي |
| المنهجية والتوقيع | شرح طريقة الاحتساب، خانتا توقيع، ختم، تذييل ببيانات الشركة |

**طريقة الحفظ كـ PDF:** اضغط «تصدير PDF» ← من نافذة الطباعة اختر الوجهة
**«حفظ كـ PDF / Save as PDF»** ← اضبط الهوامش على **«بلا / None»** ← فعّل
**«طباعة الخلفيات / Background graphics»**.

> عند اختيار «جميع المستثمرين» يخرج ملف PDF واحد، بصفحة مستقلة لكل مستثمر.

## قواعد الاحتساب

| المؤشر | المعادلة |
|---|---|
| رأس المال في نهاية شهر | مجموع الإيداعات − السحوبات حتى آخر يوم في الشهر |
| النسبة الشهرية | ربح الشهر ÷ رأس المال في نهاية ذلك الشهر × 100 |
| نسبة عائد الفترة | إجمالي أرباح الفترة ÷ **متوسط** رأس المال خلال أشهرها × 100 |
| العائد السنوي المكافئ | نسبة عائد الفترة × عدد الفترات المماثلة في السنة (شهري ×12، ربعي ×4، نصفي ×2) |
| العائد التراكمي | إجمالي الأرباح منذ البداية ÷ رأس المال القائم × 100 |

متوسط رأس المال يُحتسب على الأشهر التي كان فيها رأس مال فعلي فقط، حتى لا تنخفض النسبة
بسبب أشهر ما قبل انضمام المستثمر.

## تغيير هوية الشركة (الشعار والألوان)

### الشعار وبيانات الشركة — من داخل التطبيق
افتح **الإعدادات** وارفع الشعار (PNG أو SVG بخلفية شفافة) واكتب اسم الشركة، السطر
التعريفي، العنوان، الهاتف، البريد، الموقع، العملة، واسم الموقّع على التقارير.
كل ذلك ينعكس فوراً على الواجهة وعلى كل تقرير.

### الألوان — من ملف واحد
| ما تريد تغييره | الملف |
|---|---|
| ألوان وخطوط ونصوص الهوية (مرجع واحد) | `src/theme/brand.ts` |
| ألوان الواجهة | متغيّرات `:root` في `src/styles.css` |
| ألوان التقارير | متغيّرات `.doc` في `src/report.css` |

المتغيّرات الأساسية: `--navy-900` … `--navy-500` (الكحلي)، و`--gold` / `--gold-light` /
`--gold-dark` (الذهبي). غيّر هذه القيم فقط ليتغيّر التطبيق كله.

الخطوط (IBM Plex Sans Arabic للنصوص + Amiri للعناوين والتقارير) مستضافة محلياً في
`src/assets/fonts/`، فتظهر التقارير بنفس الشكل حتى بدون إنترنت.

## البيانات والنسخ الاحتياطي

⚠️ البيانات محفوظة في **متصفح هذا الجهاز فقط** (localStorage). لا تُرسل إلى أي خادم.

هذا يعني:
- مسح بيانات المتصفح أو استخدام جهاز آخر = لن تجد بياناتك.
- **صدّر نسخة احتياطية بانتظام** من صفحة الإعدادات (ملف JSON)، واحتفظ بها في مكان آمن.
- لاستعادة البيانات أو نقلها لجهاز آخر: «استيراد نسخة احتياطية» من نفس الصفحة.
